Workbench Mail Reader

Workbench Mail Reader is a private tool that runs on one person's own computer. It is not offered to anyone else.

Privacy policy

With read-only permission (gmail.readonly), it reads the signed-in owner's own Gmail. It cannot send, change or delete anything.

What it reads stays on that computer. It is not sold, shared, sent to any server run by this tool, or used for advertising. The sign-in is kept in a file only the owner can read.

Access can be removed at any time at myaccount.google.com/permissions.

Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
